Zero-Telemetry Guarantee

Privacy through mechanical architecture.

We believe candidate resumes should never be harvested, pooled, or stored on middleman servers. The extension is built on strict zero-egress boundaries.

No Middleman Proxies

Requests travel exclusively via HTTPS from your Chromium browser directly to api.groq.com. We do not operate an intermediary server.

100% Local Sandbox

Your resume text, contact info, and encrypted API key live strictly in chrome.storage.local on your device.

React 16+ Safe Injector

Uses native prototype setters and updates React’s internal _valueTracker so reactive state models never erase injected inputs.

Human-in-the-Loop

The extension populates inputs and highlights them for review. It intentionally never clicks the final "Submit Application" button.

Frequently Asked Questions

Engineering & Usage Details.

Do I need a paid Groq API key?

No. Groq provides a generous free Developer Plan that gives you access to ultra-fast production models like openai/gpt-oss-120b and openai/gpt-oss-20b with up to 1,000 requests per minute at zero cost.

Why doesn't the extension auto-click "Submit"?

By design. Human-in-the-loop validation protects your candidate reputation against incorrect AI responses and ensures full compliance with Chrome Web Store safety guidelines. It populates and highlights fields, leaving the final submission in your hands.

Does it bypass React or Angular synthetic input handlers?

Yes. Modern portals (like Ashby and Lever) use React controlled components that erase direct input.value assignments. JobHunt AI invokes native prototype setters on HTMLInputElement.prototype, syncs React's internal _valueTracker, and dispatches an authentic focus ➔ input ➔ change ➔ blur event sequence.

How do multi-step Workday applications behave?

Workday splits applications across multiple pages (Contact, Experience, Questions, Disclosures). Your profile stays in local storage. Simply click "Autofill fields" on each step as you advance.
